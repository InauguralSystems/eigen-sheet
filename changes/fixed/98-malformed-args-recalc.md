- One malformed formula no longer aborts the whole sheet's recalc, or (for `SWITCH`) hangs it. An incomplete range (`=IRR(A1:)`), a missing required argument, text where a number is needed, a scalar where a range is read, `=CHAR(0)`/`=CHAR(256)` and an `XLOOKUP` return array shorter than the match position now display an error in that cell (#98). Out-of-domain financial arguments such as `=PMT(0,0,100)` still abort recalc (#95).
